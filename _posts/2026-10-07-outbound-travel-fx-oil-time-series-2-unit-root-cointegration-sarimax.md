> **이 글의 결론 3줄**
> 1. 원/달러와 두바이유는 단위근 검정에서 일관되게 비정상(I(1))으로 판정되었음. 출국자수는 검정 사양에 따라 판정이 엇갈려 I(1)을 작업 가정으로 두었음.
> 2. Johansen 트레이스 통계량(21.88)이 5% 임계값(29.80)에 못 미쳐 공적분 랭크는 0임. 장기 균형관계는 확인되지 않았음.

## 분석 흐름

1. **단위근 검정**: 각 계열이 정상(평균으로 회귀)인지 비정상(충격이 누적)인지 판정
2. **공적분 검정**: 비정상 계열 간 장기 균형관계 확인
3. **모형 선택**: 공적분이 있으면 VECM, 없으면 차분 기반 모형(SARIMAX)
4. **잔차 진단과 시차 구조 확인**: 모형의 설명력, 환율의 선행 여부 확인

## 단위근 검정

### ADF와 KPSS: 귀무가설이 반대인 두 검정

- **ADF** 귀무가설: 단위근이 있음(비정상). p-value가 작으면 정상 쪽 결론
- **KPSS** 귀무가설: 정상임. p-value가 작으면 비정상 쪽 결론
- 두 검정의 결론이 일치하는지를 함께 보았음.

```python
def run_stationarity_tests(ser_data, str_name):
    result_adf = adfuller(x = ser_data.dropna(), autolag = "AIC")
    result_kpss = kpss(x = ser_data.dropna(), regression = "c", nlags = "auto")

    dict_result = {
        "series": str_name,
        "adf_stat": result_adf[0],
        "adf_pvalue": result_adf[1],
        "adf_conclusion": "정상(H0 기각)" if result_adf[1] < 0.05 else "비정상(H0 기각 못함)",
        "kpss_stat": result_kpss[0],
        "kpss_pvalue": result_kpss[1],
        "kpss_conclusion": "비정상(H0 기각)" if result_kpss[1] < 0.05 else "정상(H0 기각 못함)",
    }
    return dict_result
```

### KPSS p = 0.10은 조회표의 상한이다

- statsmodels `kpss`는 통계량을 임계값 표(10%·5%·2.5%·1%)에 대입해 p-value를 구하므로 0.01~0.10에서 잘림.
- 출국자수 KPSS 통계량 0.300 < 10% 임계값 0.347이므로, 표시는 0.10이나 실제 p-value는 0.10보다 큼.
- 이 0.10은 **10% 수준에서도 정상성을 기각하지 못하였다는 뜻**이며 비정상의 근거가 아님.
- 원/달러·두바이유의 0.01은 하한값임.

### Zivot-Andrews: 구조변화를 허용해도 결론이 바뀌는가

- 레벨이 한 번 바뀐 정상 계열에서는 ADF가 단위근을 기각하지 못하는 경향이 있음.
- Zivot-Andrews는 모든 후보 시점에 구조변화 더미를 넣고 통계량이 가장 작은 시점을 고름. 이 탐색 때문에 임계값(5% −4.81)이 일반 ADF(약 −2.88)보다 작음.
- 세 계열 모두 10% 임계값에도 미치지 못하였음. 절편 변화를 허용해도 ADF 판정은 바뀌지 않았음.
- 추정 구조변화 시점(별도 점검): 출국자수 2020.02, 원/달러 2017.02, 두바이유 2021.02

### 출국자수를 I(1)로 두는 작업 가정과 반대 근거

- **반대 근거**: 절편·기울기 동시 변화 사양(`trend = "ct"`)에서는 출국자수가 −6.622(5% 임계값 −5.07, p = 0.001)로 단위근이 기각되었음. 원/달러(p = 0.315)·두바이유(p = 0.877)는 기각되지 않았음(별도 점검).
- **I(1) 작업 가정의 근거**
  1. ADF와 Zivot-Andrews 절편 사양이 단위근을 기각하지 못하였음.
  2. 코로나 이전 표본(2015.01~2020.01)에서 KPSS가 수준 정상성(1.137, 1% 임계값 0.739)과 추세 정상성(0.254, 1% 임계값 0.216)을 모두 기각하였음(별도 점검).
  3. 한 변수가 I(0)이면 Johansen 랭크가 1 이상이어야 하나 0이 나왔음.
- `"ct"` 사양은 단위근과 구조변화가 함께 있으면 과대기각하는 경향이 있어(Lee & Strazicich, 2001) 채택하지 않았음.
- I(1)은 확정이 아니라 사양에 의존하는 가정임.

## 공적분 검정(Johansen)

### VAR 시차와 k_ar_diff의 대응

- **공적분**: 각각 I(1)인 변수들의 어떤 선형결합이 정상이 되는 성질, 즉 장기 균형관계
- Johansen 검정은 수준 VAR(p)를 재배열한 아래 식에서 행렬 Π의 rank를 검정함.

```text
ΔY_t = c + Π·Y_{t−1} + Σ_{i=1}^{p−1} Γ_i·ΔY_{t−i} + ε_t
```

- ΠY_{t−1}: 장기 정보 / ΓΔY: 단기 동학
- `coint_johansen`의 `k_ar_diff`는 ΔY의 시차 개수, 즉 **p − 1**임.
- 로그수준 VAR 시차: AIC·FPE 기준 4, BIC·HQIC 기준 2. 절약성을 우선해 BIC의 2시차를 택하였음.
- 수준 VAR(2)에 대응하는 값은 `k_ar_diff = 1`이나, 실행에는 `k_ar_diff = 2`(수준 VAR(3))가 쓰였음.
- **이 불일치는 분석 과정에서 확인된 한계**임. 시차만 바꿔 재확인한 결과를 표 2에 함께 적었음.

```python
result_johansen_full = coint_johansen(endog = df_coint_input_full, det_order = 0, k_ar_diff = 2)
result_johansen_excl = coint_johansen(endog = df_coint_input_excl, det_order = 0, k_ar_diff = 2)
```

### 트레이스 통계량과 rank 0의 의미

- 고유값(0~1)은 실제 공적분 관계에 대응하면 0보다 뚜렷이 크고, 아니면 0 근처에 머묾.
- 트레이스 통계량은 "rank ≤ r"을 귀무가설로 하는 우도비 통계량임.

```text
LR_trace(r) = −T · Σ_{i=r+1}^{n} ln(1 − λ̂_i)
```

- 전체 표본 고유값 0.117, 0.027, 0.009, 유효 관측치 T = 136
- r = 0 통계량 21.88 < 임계값 29.80 → 첫 단계에서 기각되지 않으므로 **rank 0**임.
- rank 0이면 Π가 영행렬이어서 ΠY_{t−1} 항이 사라지고, VECM은 차분 VAR과 같아짐.
- 이는 "공적분 관계가 0개라는 귀무가설을 기각할 근거가 부족하다"는 뜻이며, 공적분이 없음을 입증한 것은 아님.
- 결론이 완전히 안정적이지는 않음.
  - `k_ar_diff = 1`·코로나 제외 표본은 28.18로 임계값에 근접하였음.
  - 최대고유값 통계량으로는 이 조합에서만 r = 0이 기각되었음(22.04 > 21.13, 별도 점검).

## SARIMAX(2,1,0)×(0,1,1,12) 결과

- rank 0이므로 차분 기준으로 모형화하였음. 예측 목적과 강한 계절성을 이유로 SARIMAX를 택하였음.
- statsmodels SARIMAX는 "SARIMA 오차를 가진 회귀"임. d = 1, D = 1이면 사실상 차분된 변수끼리의 회귀가 됨.
- 차수 탐색: d·D 고정, p·q는 0~2, P·Q는 0~1, AIC 기준
- 선택 결과: (2,1,0)×(0,1,1,12), AIC −31.34, BIC −9.52

```python
model_sarimax_best = SARIMAX(
    endog = df_master_full["log_outbound"],
    exog = df_master_full[list_exog_cols_final],
    order = dict_best_order["order"],
    seasonal_order = dict_best_order["seasonal_order"],
    enforce_stationarity = False,
    enforce_invertibility = False,
)
result_sarimax_best = model_sarimax_best.fit(disp = False)
print(result_sarimax_best.summary())
```

- **환율 계수**: p = 0.380으로 유의하지 않음. 월평균 환율이 측정오차를 가진 대리변수여서 계수가 0 쪽으로 편향되었을 가능성이 있음.
- **유가 계수**: 양(+)으로 유의하며 직관과 반대임.
  - 공적분이 없는 상태에서 남은 공통 추세·구조변화를 유가가 흡수하였을 가능성이 있음.
  - 코로나 더미 밖에 있는 2026.03 급등이 계수에 영향을 주었는지 점검이 필요함.

### 잔차 진단

- **Ljung-Box(시차 12)**: 47.47, p = 0.000004. 잔차 자기상관이 남아 계수 유의성 해석에도 한계가 있음.
- **정규성**: Jarque-Bera 268.67(p < 0.001), 첨도 10.33. 코로나 국면의 급락·회복이 이상치로 작용한 결과로 보임.
- **ma.S.L12 = −1.0000**(표준오차 2068.6): 계절차분 과잉의 신호이거나, 코로나 충격과 계절차분의 결합이 만든 구조일 수 있음.

- 전체 표본의 구조는 코로나 붕괴·회복에서 생겼을 가능성이 있음.

## CCF: 환율이 출국자수에 선행하는가

- 대상: 출국자수와 원/달러의 전월 대비 로그차분, 시차 0~12개월 교차상관(노트북에 그림 없이 표로만 출력)
- 최대값: 시차 0 −0.136, 시차 5 0.132
- 모든 시차가 신뢰한계(약 ±0.17, n = 138) 안에 있음.
- 이 계열은 코로나 구간과 계절성을 포함하고 있어 이 신뢰한계를 그대로 적용하기 어려움.

## 정리

- 장기 균형관계는 확인되지 않았음.
- 단기 계수는 유의하지 않거나 부호가 반대였음.
- 3편에서는 이 모형의 예측을 표본외 검증과 사후 검증으로 평가함.
