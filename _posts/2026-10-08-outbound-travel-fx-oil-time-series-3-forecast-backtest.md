3. 이 예측은 믿을 만한가: 사후 검증 ← 이 글

> **이 글의 결론 3줄**
> 1. 1개월 앞 표본외 검증에서 환율·유가를 넣은 SARIMAX(MASE 0.189)는 외생변수 없는 SARIMA(0.124)보다 부정확하였고, Diebold-Mariano 통계량 +2.19로 그 차이가 유의하였음.
> 2. 같은 절차로 2025.06 시점에 13개월을 예측해 실측과 비교한 결과, MAPE 22.7%로 작년 같은 달 값을 그대로 쓴 예측(4.8%)보다 나빴음.
> 3. 주된 원인은 회복추세항 고정이 차분 모형에서 매월 약 3.6%씩 누적되는 감소 가정으로 작용한 것임. 유의한 관계를 찾지 못한 것 자체가 이 분석의 결과임.

## 표본외 검증: MASE 0.189 vs 0.124

- **MASE(Mean Absolute Scaled Error)**: 예측 오차의 평균 절대값 ÷ 학습 구간에서 "12개월 전 값으로 예측"하였을 때의 평균 절대 오차
- 단위가 없고, 작을수록 정확함.

```python
def compute_mase(arr_actual, arr_forecast, arr_train_history, int_season_length = 12):
    arr_actual = np.array(arr_actual)
    arr_forecast = np.array(arr_forecast)
    arr_train_history = np.array(arr_train_history)

    float_scale = np.mean(
        np.abs(arr_train_history[int_season_length:] - arr_train_history[:-int_season_length])
    )
    float_mase = np.mean(np.abs(arr_actual - arr_forecast)) / float_scale
    return float_mase
```

- 검증 방식: rolling-origin
  - 처음 84개월로 학습 → 다음 1개월 예측 → 학습 구간을 한 달씩 늘리며 반복
- 차수는 2편과 같은 (2,1,0)×(0,1,1,12)이며, 외생변수 포함 여부만 다르게 하였음.

## Diebold-Mariano 검정: +2.19

- 목적: MASE 차이가 우연인지 확인
- 검정 내용: 두 모형의 제곱오차 차이의 평균이 0인지 검정, 소표본 보정(Harvey-Leybourne-Newbold) 적용
- 부호 해석: 음수면 SARIMAX 우위, 양수면 기준선(SARIMA) 우위

| 모형 | 1개월 앞 평균 MASE |
|---|---|
| SARIMAX(환율·유가·코로나 외생변수 포함) | 0.189 |
| SARIMA(외생변수 없음, 기준선) | 0.124 |
| Diebold-Mariano 통계량 | **+2.19** (절대값 > 1.96, 기준선 우위) |

*표 1. 1개월 앞 표본외 검증 결과*

- 환율·유가 추가는 1개월 앞 예측 정확도를 오히려 낮췄음.
- 2편의 공적분 미확인 결과와 함께 보면, 이 변수들이 출국자수와 안정적인 단기 예측 관계를 갖지 못한다는 근거임.

## 핵심: 1년 전에 예측했다면

- 시나리오 예측의 적중 여부는 아직 알 수 없으므로, 같은 절차를 1년 전 시점에 적용하였음.
- 설정: 2025.06까지의 자료로 적합 → 2025.07~2026.07(13개월) 예측 → 실측치와 비교
- 비교 대상
  - SARIMAX 4종: 미래 외생변수 투입 방식(환율·유가 실측 여부 × 회복추세항 연장 여부)
  - 기준 예측 2종: SARIMA, 계절 naive
- 외생변수를 모두 마지막 값으로 고정한 경우(앞의 시나리오 예측과 동일)를 그래프 범례와 표에서 "10절 방식"(노트북의 절 번호)이라 부름.

```python
def build_backtest_exog(bool_realized_price, bool_trend_extend):
    # bool_realized_price: 환율·유가를 실측치로 교체 / bool_trend_extend: 회복추세항을 정의대로(매월 +1) 연장
    df_exog = df_exog_hold.copy()
    if bool_realized_price:
        df_exog["log_usd_krw"] = df_backtest_test["log_usd_krw"]
        df_exog["log_dubai"] = df_backtest_test["log_dubai"]
    if bool_trend_extend:
        df_exog["covid_recovery_trend"] = df_backtest_test["covid_recovery_trend"]
    return df_exog
```

## 진단: 왜 맞지 않았는가

### 1. 회복추세항 고정이 누적 감소 가정이 되는 구조

- SARIMAX는 외생변수에 Δ1Δ12가 적용된 형태로 작동함(2편 참고).
- 학습표본의 2024년 이후 회복추세항은 매월 +1이므로 Δ1Δ12가 0임.
- 예측 구간에서 이 값을 고정하면 Δ1이 0이 되어 Δ1Δ12가 12개월 동안 −1이 됨. 계수(0.0363)만큼의 음(−)의 충격이 매월 누적됨.

```text
(고정 시 예측) ÷ (연장 시 예측) ≈ exp(−0.0363 × h)      h: 예측 시차(개월)
```

- 검산: 2026.04(h = 10) 예측 1,385,643 ÷ 1,992,555 ≈ 0.70 = exp(−0.363)
- **이 모형에서 "고정"은 중립적 가정이 아니라 매월 약 3.6%씩 누적되는 감소 가정임.**
- 회복추세항만 연장해도 MAPE 8.0%, 평균오차 −0.6%로 줄었음.
- 이 설정은 분석 과정에서 확인된 한계이며, 앞의 시나리오 예측에도 그대로 들어 있음.

### 2. 코로나 더미의 시점 불일치

- 더미 종료는 2022.12이나, 실제 회복은 2022년 중반에 시작해 2023.12에 2019년 수준에 닿았음.
- 차분 후 더미 펄스와 실제 충격의 시점도 1~2개월 어긋남.
- 결과: 더미 계수가 직관과 반대인 양(+)(학습표본 0.1245)으로 추정되었고 잔차 분산이 커졌음.

### 3. 모형에 빠진 명절 더미

![연도별 설·추석 소속월 더미 격자, 2015~2026년](/assets/images/posts/outbound-ts-part3_03_holiday_dummy_grid.png)

*그림 3. 설·추석 소속월 더미(연도 × 월). 공란은 해당 없음 또는 미관측이다.*

**이 그림에서 볼 것:** 설과 추석이 놓인 달이 해마다 바뀐다. 2023년 추석은 10월로 표시되어 있다.

- 명절 더미는 만들어 두었으나 모형에 넣지 않았음.
- 2025.10은 모든 예측이 실측(267.8만 명)을 크게 밑돌았음(계절 naive −11%, SARIMA −12%).
  - 2025년 추석 연휴가 10월에 길게 놓인 효과로 해석됨.
  - 출국자수 Δ12도 2025.09 −3.3, 2025.10 +11.7로 크게 엇갈렸음.
- 더미 자체의 문제
  - 2023년 추석 당일은 9월 29일(연휴 9.28~10.3)인데 10월로 코딩되어 있음.
  - "추석 당일 소속월"과 "연휴 일수가 많은 달" 중 기준을 정하고 전 연도에 같은 기준을 적용해야 함.

### 4. 환율·유가 실측치를 알아도 나아지지 않았다

- 미래 환율·유가를 정확히 안다고 가정한 경우
  - 10절 방식 대비: MAPE 22.7% → 20.4%로 소폭 감소
  - 추세 연장 기준: 8.0% → 17.5%로 오히려 악화
- 원인: 학습표본의 두바이유 계수가 +0.93(직관과 반대 부호)이어서, 2026.03 두바이유 급등(+61.5%)이 출국자수 예측을 끌어올렸음.
- 급등 원인은 이 자료만으로 확인되지 않음. [확인 필요]

### 5. 지나치게 넓은 95% 예측구간

- 10절 방식의 95% 예측구간: 2025.07 154만~318만 명 → 2026.07 13만~2,453만 명
- 13개월 실측치가 모두 구간 안에 들어왔으나, 구간이 지나치게 넓어서 생긴 결과이며 잘 보정되었다는 근거가 아님.
- 원인
  - 코로나 충격이 포함된 학습표본에서 잔차분산이 크게 추정되었음(σ² = 0.0308, 월 로그 표준편차 약 0.18).
  - 이중 차분을 거치며 예측분산이 누적되었음.
- 검증 자체의 한계
  - 예측 시작점이 하나(2025.06)인 단일 경로 비교여서 우연의 영향을 배제할 수 없음.
  - 차수는 검증 구간을 포함한 전체 표본에서 선택되었음.

## 결론: 유의한 관계를 찾지 못한 것 자체가 결과다

- 세 편에 걸쳐 확인한 내용
  1. 원/달러·두바이유와 출국자수 사이의 장기 공적분 관계는 확인되지 않았음.
  2. 단기 계수는 환율이 유의하지 않고, 유가는 직관과 반대 부호였음.
  3. 외생변수를 넣은 모형은 1개월 앞 예측과 13개월 사후 검증 모두에서 외생변수 없는 모형과 작년 같은 달 값보다 부정확하였음.
- "환율이 오르면 해외여행이 줄어든다"는 설명은 이 데이터와 사양에서는 뒷받침되지 않음.
- 이 분석에서 얻은 결론
  - 유의하지 않은 결과를 유의한 것처럼 해석하지 않음.
  - 모형을 가장 단순한 기준 예측과 먼저 비교함.

## 후속 과제

- **엔화·목적지 가중 환율**: 원/달러만으로는 엔저 경로가 빠지므로, 목적지별 출국 비중으로 가중한 여행 실효환율을 검토함.
- **ARDL 경계검정**: 출국자수의 적분 차수가 사양에 따라 엇갈리므로, 차수를 미리 확정하지 않는 방법으로 장기관계를 교차 확인함.
- **명절 더미**: 판정 기준을 명시해 다시 코딩하고 모형에 포함함.
- **결정론적 항 재설계**: 회복추세항을 연장하거나 2023년 구간 더미로 바꾸고, 코로나 충격 월은 펄스 더미로 처리함.
- **여러 시점에서의 예측 검증**: 예측 시작점을 여러 개 두고 다단계 오차를 평균하는 rolling-origin 평가로 단일 경로 비교의 한계를 보완함.
